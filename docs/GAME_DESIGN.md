# BREAK TACTICS — ゲーム仕様・現行実装

更新日: 2026-11-25
対象: ボスラッシュ版（`Assets/Scenes/BossRush.unity`）。数値は現在のコードとアセットの設定値で、完成バランスを保証しない。

## 1. ゲーム概要

- Unity 2023.2.22f1 / C# の2Dターン制ボスラッシュ。ビルド対象は BossRush シーンのみ。
- 職業とスキルを編成し、1対1の戦闘を3連戦で勝ち抜く。
- 顔・手・脚・腹を狙う。本体HPと部位HPは別管理、腹は破壊不能。
- 中核は、敵の攻撃予告を読み、部位破壊・封印・妨害・弱点で戦況を変えること。
- 旧構成の町・クエスト階層・戦闘後の成長選択と特殊報酬（生命吸収・集中攻撃・精密射撃）・忍者の体勢崩しは、現在のコードにはない。

## 2. ゲームの流れ

1. 敵候補8体から、重複なしで3体を抽選する。
2. 準備画面で次の対戦相手を確認し、職業とスキルを選ぶ。
3. 戦闘に勝つと、前の編成を引き継いで次の準備画面へ進む。
4. 3勝で GAME CLEAR、敗北で GAME OVER。RETRY はシーンを読み直し、抽選と編成を最初からやり直す。

- 職業変更は、最初の選択を除き1回の挑戦につき1回まで。編成が確定したときに回数を数える。
- 各戦の開始時にHP/MPを全回復し、クールダウン・毒・戦闘限定の効果を初期化する。

## 3. 編成

- 固有スキル2つ（職業ごとの3候補から）と、自由スキル3つ（全職共通の5候補から）の合計5つ。同じスキルは重複できない。
- 職業を変えると固有スキルの選択は解除し、自由スキルの選択は残す。
- 戦闘のスキル欄は固有枠、自由枠の順に並べ、1ページ4枠で表示する。

| 職業 | HP | MP | AT | MAG | DEF | MDEF | 固有スキル候補 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 戦士 | 1000 | 100 | 55 | 40 | 4 | 8 | 破砕斬、守りの一閃、戦巧斬 |
| 魔法使い | 800 | 150 | 30 | 80 | 0 | 20 | 炎槍・穿破、氷獄・封圧、アーケインバースト |
| バーサーカー | 1500 | 60 | 95 | 10 | 0 | 0 | 裂断、血の代償、不屈の雄叫び |

- 自由スキル候補: 堅守、狙い澄まし、解毒、応急処置、牽制打ち。
- 戦士の固有パッシブ「戦技習得」: 顔の破壊でMPコスト20%軽減、手の破壊で物理ダメージ1.15倍、脚の破壊で受ける直接ダメージ0.85倍。各種1回、その戦闘中のみ。
- `PlayerData` の `startSkills` は旧所持スキルのデータで、ボスラッシュの編成候補には使わない。候補はシーンの `BossRushBattleController` に登録する。

## 4. 戦闘

### 部位破壊

| 部位 | 破壊時の効果 |
| --- | --- |
| 顔 | 敵のDEFとMDEFを各20下げる（下限0） |
| 手 | 敵の通常攻撃の命中率を0.1下げる（破壊ごとに加算） |
| 脚 | そのターンからプレイヤーが1ターンに2回行動できる |
| 腹 | 破壊できない |

### ダメージ・状態

- 基本ダメージ: √(威力 × ATまたはMAG ÷ DEFまたはMDEF) × 3。防御の分母は最低1、通常攻撃の威力は100。
- 弱点・耐性の倍率は、本体と部位の両方に適用する。
- カウンター: 実際に減った本体HP×1.7を反射する。毒・反射・自傷はガード軽減の対象外。
- 毒: 3ターン、最大HPの5%。火傷: 3ターン、最大HPの通常5%・強化3%・ボス2%。凍結: 3ターン、AT/MAGを50%下げる。
- 敵の火傷と凍結は同時に付かない。

### 予告・妨害・封印

- 戦士は「ラッシュ」を予告することがあり、竜騎士は「強化ラッシュ」、魔導監察官は「禁呪光槍」、血斧の略奪者は「破山斧」を1ターン、騎士王は「王の重撃」を2ターン構える。
- 予告中に、まだ壊れていない手を破壊すると妨害し、敵はそのターン行動しない。破壊済みの手では妨害できない。
- 騎士王: HP75%以下で毒、50%以下で1回限りの専用行動、35%以下で重撃を解禁する。手1つの破壊でマジックガード、手2つで毒と重撃、顔で回復を封印する。
- 魔導監察官: 顔の破壊で魔力徴収、手の破壊で禁呪光槍を封印する。
- 血斧の略奪者: 顔の破壊で血気、手2つの破壊で破山斧を封印する。
- 護符の巡礼者: 顔の破壊で再生祈祷、手の破壊で護符障壁を封印する。

## 6. コードの担当

| クラス | 担当 |
| --- | --- |
| `BossRushRunController` | 対戦相手の抽選、連戦の進行、結果画面、再挑戦 |
| `BossRushRunState` | 編成の検証、職業変更回数 |
| `BossRushBattleController` | 準備画面と戦闘の接続、開始・終了の通知 |
| `BossRushPreparationUI` | 職業とスキルの選択画面 |
| `BattleManager` | 1戦の進行 |
| `EnemyAI` と各RoleAction | 敵の行動選択 |
| `SkillExecutor` / `SkillUseRules` | スキルの効果 / 使用条件とコスト |
| `PlayerBattleState` / `EnemyBattleState` | 戦闘限定の状態 |

## 7. 実装・検証の扱い

- 予告した行動は保持し、実行直前に再抽選しない。
- `SkillId` は並べ替えない。固有枠と自由枠の判定は、番号の連続した範囲に依存する。
- アセットは対象版UnityのAPIで作成・更新し、GUIDを再利用する。
- Unityコンパイル、EditMode、PlayMode、自動描画画像、手動プレイを区別して報告する。
