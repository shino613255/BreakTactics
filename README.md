# BREAK TACTICS

職業とスキルを編成し、敵の部位を狙って3連戦を突破する、ターン制のボスラッシュゲームです。どの部位を先に壊すかで、敵の防御力や自分の行動回数が変わります。

## 遊び方

1. **職業を選ぶ**  
   戦士・魔法使い・バーサーカーの3職業から選びます。準備画面には次の対戦相手が表示されます。
2. **スキルを編成する**  
   選んだ職業の固有スキルを2つ、全職業で使える自由スキルを3つ選び、戦闘を開始します。同じカードをもう一度クリックすると選択を解除できます。
3. **敵の部位を狙う**  
   顔を壊すと敵の防御と魔法防御が下がり、手を壊すと敵の命中率が下がります。脚を壊すと、そのターンから1ターンに2回行動できます。腹は攻撃できますが、部位破壊はできません。スキル選びでは、消費MPとクールダウンも確認します。
4. **3戦を勝ち抜く**  
   1回の挑戦で、8体の候補から重複なしで選ばれた3体と戦います。勝利すると前の編成を引き継いで次の準備画面へ進みます。編成は戦闘ごとに見直せます。最初の職業選択を除き、職業の変更は挑戦中に1回までです。HPとMPは各戦の開始時に全回復します。

3勝で **GAME CLEAR**、途中で負けると **GAME OVER** です。結果画面の **RETRY** で、対戦相手の抽選と編成を最初からやり直せます。

## 操作

| 操作 | 内容 |
| --- | --- |
| 敵の部位を左クリック | 通常攻撃。攻撃スキル選択中は、その部位にスキルを使う |
| 「スキル」をクリック | 編成したスキルの一覧を開く。自分が対象のスキルは選択すると発動する |
| `V` キー | 部位の判定範囲を表示・非表示にする。顔は赤、手は青、脚は緑、腹は黄 |
| 戦闘メッセージ表示中に左クリック | テキストを最後まで表示する、または次のメッセージに進める |

## 実装の見どころ

- **編成と連戦進行**  
  職業とスキルの組み合わせは編成クラスで検証します。連戦を管理するクラスは戦闘の開始・終了イベントを受け取り、次戦への移行と最終結果を担当します。
- **部位ごとの戦闘処理**  
  敵の部位ごとにクリックの判定範囲と耐久値を持ち、破壊した部位に応じて敵の能力やプレイヤーの行動回数を変えています。
